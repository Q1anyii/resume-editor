# 简历编辑器

单文件、离线可用的简历编辑器：左边表单改，右边实时 A4 预览，一键导出 PDF 或干净的 HTML。
一个 `.html` 文件就是全部——没有构建、没有依赖服务、不用装环境，双击就能用。

> 这个仓库只放编辑器本身和它的改动日志。简历内容、针对各家公司的定制版本留在上一层目录，不在这里。

## 用法

1. 双击 `简历编辑器.html`，用 Chrome / Edge 打开。
2. 内容自动存在本机 `localStorage`（关掉再开还在），不上传任何服务器。
3. 改完点右上角「导出 PDF」→ 先弹一个大窗口看整页效果，确认后直接生成 PDF 文件（不弹打印窗口）；要文字可选中的矢量版，点「打印 · 矢量」→ 打印窗口里「目标」选「另存为 PDF」、纸张 A4、边距「无」；要一份能直接发出去的网页，点「导出 HTML」。

## 功能

**编辑**

- 左侧改、右侧固定 A4 容器（210mm × 297mm）实时预览，随窗口大小自动缩放
- 最左一列模块跳转条：点「个人」「教育」「项目」直接跳到对应卡片，滚动时高亮当前模块
- 模块可增删、折叠、隐藏（◉ 隐藏后不进预览与 PDF）、拖拽调序
- 每个模块里的条目（项目 / 经历 / 教育 / 技能条目 / 段落）可增删、折叠、拖拽调序
- 每条 bullet 可增删、折叠、隐藏、在本条目内拖拽调序
- 拖拽用指针事件 + 蓝色插入线指示落点，松手才落数据，不闪屏、不丢滚动位置

**排版与配色**

- 4 套排版预设：标准 9.3pt/1.55、紧凑 8.8pt/1.42、舒展 10pt/1.72、疏朗 9pt/1.85
- 排版预设只管字号、行距、模块距；8 套主题配色（经典深蓝 / 石墨黑 / 墨绿 / 酒红 / 石板蓝 / 暖褐 / 深青 / 黛紫）只管颜色。两者互相独立，可任意组合
- 也可用四条滑块（字号 / 行距 / 模块距 / 左栏宽度）继续微调，微调后预设标记为「自定义」
- 左栏宽度也能直接拖中间的分隔条

**内容处理**

- 联系行逐项编辑：意向城市 / 电话 / 邮箱 / GitHub / 作品主页 / 自定义，预览自动拼回一行，网址缺协议时补 `https://` 并生成可点击链接
- 自定义加粗：选中文字点 B，或在文本框里手写 `**文字**`；预览、PDF、截图都按加粗渲染
- 导入已有简历 HTML：按模板结构（`h1` 姓名 → 头部 3 个 `p` → `h2` 分段 → `h3` 项目 → `ul/li` bullet）解析成模块与 bullet，覆盖当前内容；外面套了几层 `main` / `div` 容器也能读
- 导出 HTML：见下方「导出」表
- 导出 / 导入 JSON 配置：换机器或存档用；导出时自动剔除 API Key
- 超页提示：右上角实时显示「单页 · 余 xx pt」或「超出 1 页约 xx pt」

**AI 对齐 JD（可选）**

把岗位描述粘进「目标 JD」，填 Base URL（OpenAI 兼容端点，默认 DeepSeek）、模型、API Key，选范围（整份或某个模块），点生成。

模型只输出结构化修改建议，页面逐条列出「原文 → 建议 → 理由」，你自己决定采用或忽略；不会直接改简历，也不会新增项目、技术、数字或时间。模块卡片头的 ✦ 可以只对那一块跑。建议列表在框内滚动。

- Key 只存在这台电脑的 localStorage，导出配置不带
- 请求直连你填的端点，不经中转
- 提示词内置口径红线：不编造指标、不写没做过的能力、部署情况只写真实的那一个
- **System Prompt 可自定义**：留空就用内置那份（约 1000 字，含口径红线）；填了完全替换。「填入默认」把内置文本灌进输入框供你改，「恢复默认」清空回落。自定义时记得保留「只输出 JSON」那条，否则返回内容解析不了；口径红线兜底（禁用 plan-and-execute、禁止「两个项目都部署」等）仍在代码里生效

## 导出

| 按钮 | 做法 | 结果 |
|---|---|---|
| 导出 PDF | 先弹大窗预览整页 → 确认后 html2canvas 截 A4 + jsPDF 合成 | 直接得到 `.pdf` 文件，不弹打印窗口；位图约 240dpi，文字不可选中/ATS 可能读不到。导出瞬间界面空白一两秒属正常 |
| 打印 · 矢量 | 走系统打印 | 矢量 PDF，文字可选中、可被 ATS 解析（正式投递用这个） |
| 导出 HTML | 按当前状态生成一份语义化简历网页 | 单文件、样式内联，双击即看、可当附件投递；日后还能用「导入 HTML」原样读回来继续改 |

导出的 PDF 与 HTML 文件名统一为 `姓名-求职意向-简历`（求职意向取岗位行 `｜` 之前那段，如 `张三-IT 工程师（开发方向）-简历.pdf`）。

「导出 HTML」写进去的是当前的字号 / 行距 / 模块距 / 主题色与内容：隐藏的模块和 bullet 不会出现在文件里，加粗、链接、条目小标题都保留；导出的文件再用「导入 HTML」读回，模块数、条目数、bullet 小标题与原状态一致（已做 round-trip 自测）。

「导出 PDF」默认出位图：纯前端要排版出矢量中文，得把整套中文字体嵌进 PDF（单字体就 10MB 量级），投递不合适。所以走 240dpi 位图（A4 约 1985 × 2805 px），视觉上与预览一致、打印够用；要可检索的矢量文本，用「打印 · 矢量」。预览弹窗只读当前状态，改了内容再点一次即可，关掉不留痕迹。

## 技术说明

- 原生 JS，无框架、无构建工具；状态是一个普通对象 + 重渲染函数
- 外部依赖只有两个 CDN 库（jsDelivr 上的 html2canvas 1.4.1、jspdf 2.5.1），仅「图像版 PDF」用到；断网时会自动退回系统打印
- 页面结构：`.rail` 模块跳转条 / `.editor` 左栏表单 / `.splitter` 宽度拖拽 / `.pvScroll → .pageWrap → .page` 右侧 A4
- 状态键 `resume-editor-v1`；折叠状态存在 `state.ui['f:'+key]`，模块 `m-<id>`、面板 `p-<name>`、bullet `b:<模块>:<条目>:<序号>`

## 本地无头验证（可选）

改完想自己验一遍，可以复制一份到临时目录，在 `</body>` 前注入一段 probe 脚本，再用 Chrome 无头跑：

```powershell
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu --no-sandbox `
  --user-data-dir="$env:TEMP\cprof" --virtual-time-budget=12000 --dump-dom "file:///<临时文件>" `
  | Out-File -FilePath "$env:TEMP\dom.html" -Encoding utf8
```

`--dump-dom` 里搜注入的 `<pre id="__probe">` 即可看到断言结果。截图把 `--dump-dom` 换成 `--screenshot="<png>"` 并加 `--window-size=1680,1050`。
