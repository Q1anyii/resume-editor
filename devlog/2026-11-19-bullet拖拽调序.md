# bullet 支持拖拽调序

日期：2026-11-19
文件：`简历编辑器.html`

## 需求

项目经历 / 实习经历下的每一条 bullet，原来只能靠「✕ 删除 + ＋添加」调整顺序，等于要重录文本。要能像模块卡片那样拖一下换位置。

## 实现

数据层不用改：`m.items[i].bullets` 本来就是数组，同条目内 `splice` 换位即可。

- **模板**（project / intern 两个分支）：每条 bullet 加 `data-i` / `data-bi`，`bullet-head` 左侧改成 `<span class="bh-left">` 包住新增的 `⠿` 手柄（`.bhandle`，`draggable="true"`）与序号。
- **CSS** 三行：`.bh-left{display:flex;align-items:center;gap:5px}`、`.bullet.dragging{opacity:.45}`、`.bullet.over{border-color:var(--brand-2);box-shadow:0 0 0 3px rgba(47,111,187,.12)}`。
- **JS**：模块级 `bulletDrag = {mid, i, bi}`；`bindBulletDrag()` 给每个 `.bullet[data-bi]` 绑手柄 dragstart/dragend 与整行 dragover/dragleave/drop；`moveBullet(mid, i, from, to)` 用 `splice` 移位，然后 `renderEditor() + renderPreview() + checkOverflow() + applyZoom() + save()`，序号与预览同步刷新。
- `renderEditor()` 末尾在 `bindDrag()` 之后接 `bindBulletDrag()`，因为左栏每次都是整体重绘，监听器必须重绑。

## 作用域约束

只允许同一 `mid` + 同一 `i`（同一条项目 / 经历）内调序；跨条目拖动直接忽略。

理由：bullet 的内容属于那条经历（哪家公司、哪个项目、什么时间），把它拖到另一条经历下面等于改事实，简历里不允许。要跨条目搬内容，应该走复制文字再删除原条目的路径。

## 验证

无头 Chrome + 真实 `DragEvent` 链路（不是直接调函数）：

| 检查 | 结果 |
|---|---|
| 项目模块 bullet / 手柄数量 | 9 / 9（项目乙 5 条 + 项目甲 4 条） |
| `data-i` / `data-bi` 映射 | `0/0,1/0,2/0,3/0,4/0,0/1,1/1,2/1,3/1` 正确 |
| dragstart 后 | `bullet dragging`，`bulletDrag.bi = 0` |
| dragover 后 | 目标行 `over=true`，`defaultPrevented` 生效 |
| drop 后顺序 | `5个业务服 / AI的写 / 客户端上报 / Redisson / 独立met` → `AI的写 / 客户端上报 / 5个业务服 / Redisson / 独立met` |
| drop 后状态 | `bulletDrag` 归 null，高亮清除 |
| 跨条目 drop | 被拒，9 条不变 |
| 序号标签 | `bullet 1…5 / bullet 1…4` 重排正确 |
| 越界参数 | `moveBullet(…, 0, 99)` 静默不动作 |

截图确认左栏每条 bullet 头部有 `⠿` 手柄、与 ✕ 分行左右两侧，观感与模块卡一致。

## 取舍

- 不做跨条目拖拽（同上，语义不允许）。
- 拖动落点按「插到目标行位置」处理，不区分上半/下半区插入——条数不多，够用；真需要精细插入时按行中点判断 `clientY` 即可。
