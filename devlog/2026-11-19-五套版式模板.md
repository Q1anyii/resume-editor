# 五套版式模板：一套语义结构，五份版面骨架

日期：2026-11-19
涉及文件：`简历编辑器.html`、`README.md`

## 需求

之前的「排版」只有 4 套间距预设（标准 / 紧凑 / 舒展 / 疏朗），本质是字号、行距、模块距的微调；主题配色是另一套独立维度。要的是**真正的模板差异**：抬头放哪、要不要分栏、时间贴哪一列、模块是否上底纹——像外面拿到的几种简历模板，但彼此要拉开距离，不做同一套骨架换颜色。

硬性约束：换版式不能破坏已有能力（模块级折叠 / 隐藏 / 拖拽调序、bullet 折叠 / 隐藏 / 拖拽），且**预览、导出 HTML、导出 PDF（位图）、打印 · 矢量四条路径必须一致**。

## 方案

### 一套语义结构，多份 CSS

不改生成的节点语义（仍是 `h1` 姓名 / `h2` 模块 / `h3` 条目标题 / `p` / `ul>li`），只让版式决定**容器**与**CSS**：

- `buildBody(tpl)`：唯一正文生成入口，预览与导出 HTML 都调它；`tpl` 决定外层是 `header` + 顺序流（banner / card）、`aside` + `main` 双栏（sidebar），还是 `div.r-tl-item` 时间列（timeline）。
- `tplCss(root)`：一份函数返回全部版式 CSS，`root` 传 `'.page'`（预览）或 `'.resume'`（导出），同一套规则换个前缀就复用。
- `state.layout.tpl`：版式存进排版状态，与 `fs / lh / gap / preset` 平级；`tplId()` 对非法值回落 `classic`。
- `applyLayout()` 里 `syncTplClass()` 把 `tpl-banner / tpl-sidebar / tpl-timeline / tpl-card` 挂到 `.page` 上；导出时同样挂到 `.resume` 上。

### 五套骨架

| 版式 | 抬头 | 模块标题 | 时间 | 差异点 |
|---|---|---|---|---|
| 经典单栏 | 顶格 | 粗下划线 | 行内 | 与改造前视觉一致，作基准 |
| 横幅抬头 | 通栏色块（负 margin 出血到页边） | 左侧 4.2pt 竖色块 + 1pt 淡线 | 行内 | 模板块整体前移，摘要加浅底 + 左竖条 |
| 左侧深栏 | 压在 64mm 深色左栏里（白字） | 白字 + 半透明白线 | 行内 | `style: list` 的模块进左栏，其余走右栏 |
| 时间轴 | 居中 + 字距 | 13pt 短横线 + 字距 | 左侧 26mm 列、右对齐、1pt 竖线 | 姓名 / 意向 / 联系居中，联系行下双线 |
| 卡片分区 | 居中 + 双线下框 | 左侧 2.6pt 色条，无下划线 | 行内 | 每个模块一张 `--accent-bg` 圆角卡片 |

主题色通过 CSS 变量（`--accent`、`--accent-line`、`--accent-bg` …）渗进全部五套骨架，所以「版式 × 主题 × 间距」是自由组合，不用为每个组合各写一份模板。

### 四条路径怎么保持一致

1. **预览**：`pageEl.innerHTML = buildBody(tplId())`，`.page` 挂 tpl class。
2. **导出 HTML**：`exportHtmlSource()` 改用 `buildBody(tpl)`，并在 `<style>` 里追加 `tplCss('.resume')`、`<main>` 上挂同样的 tpl class。
3. **导出 PDF（位图）**：`openPdfPreview()` 的克隆页同步 `className` 与整套 `PAGE_VARS`；`buildExportBox()` 同样。
4. **打印 · 矢量**：打印走页面本身，`.page` 已带 tpl class，`@media print` 的 `.page{padding…}` 被 `.page.tpl-*` 更高优先级覆盖。

## 实现要点与踩坑

1. **`PAGE_VARS` 抽常量**。原来位图导出与 PDF 预览各抄一份变量白名单，新增 `--accent-line` 时差点只改一处——现在只有一份 `PAGE_VARS`，克隆页和导出盒子共用。

2. **项目 meta / stack 必须留在同一个 `<p>` 里**。`r-meta` 与 `r-code`（技术栈）原来各占一个 `<p>`，导入解析会把第二个 `p` 当成 `desc`。改成同一 `p` 内 `<br>` 分行，导入按行拆回「meta / stack」；`desc` 单独一段不受影响。

3. **时间轴的时间要藏而可读**。时间轴把时间从 `meta` 串里抽到左列显示，但导出文件里必须留一份原文，否则「导出 → 再导入」丢时间。做法是行尾塞 `<code class="r-code tl-hide">时间</code>`：视觉隐藏，`parseResumeHtml` 单独取出来拼回 `meta` 首位。

4. **摘要可能排在模块之后**。侧栏版式的文档顺序是「aside(姓名/意向/联系/技能) → main(摘要/教育/…)」，导入时 `cur` 已指向技能模块，摘要段被当成第 4 条技能。修法：`fill()` 里先按 class 认 `summary`，归到 `meta.summary` 后直接 return。

5. **侧栏撑满一页会打出第二张空白页**。`.r-cols{min-height:297mm}` 在 A4 上亚像素溢出，`--print-to-pdf` 出 2 页。改成 `296.5mm`，并且 `min-height` 只挂在 `.r-cols` 上、`.r-side` 靠 grid `stretch` 拉满，色带依然铺满整页。

6. **`syncTplClass()` 不能用 `pageEl.className = ...` 整体赋值**。`checkOverflow()` 会临时加 `measuring` 类，整体赋值会把它冲掉。改成 `classList` 增删。

7. **每个模块包一层 `section.r-sec`**。卡片版式靠这层上底纹；其余版式这层无样式，父子 margin 仍会折叠，间距与折叠能力和改造前一致。

8. **「恢复默认」保留版式**。它本是还原字号 / 行距 / 模块距，若把 `state.layout` 整体替换会连带把版式重置成经典单栏——现在显式保留 `tpl: tplId()`。

## 验证

用 Chrome headless（独立 `--user-data-dir`、`--virtual-time-budget`）跑了五轮：

- **五套预览**（`probe.html?tpl=…`）：全部 `data-probe=ready`，无 JS 报错；逐一目视 —— 经典单栏与改造前一致，横幅色块通栏、侧栏白字与大留白、时间轴左列竖线、卡片底纹圆角，五套互不相似。
- **五套导出 HTML**：分别独立渲染截图，与预览同版式；导出体积 9.9k–10.4k 字符。
- **往返**：`parseResumeHtml(exportHtmlSource())`，四套顺序不变、模块 4/4、条目数 `1,2,1,3` 一致、项目 `meta` 含时间、技能 `label` 保留；侧栏顺序变为「核心技能 → 教育 → 项目 → 实习」（左右栏被拍平，数据不缺），按标题复核项目字段：`meta` 含时间、`stack`、`desc`、两条 bullet 全在。卡片版式同经典，通过。
- **PDF 预览弹窗**：`openPdfPreview()` 后截图，侧栏与时间轴在弹窗内与右侧预览同版式（此前用户反馈过「PDF 没对齐」，这条是重点回归项）。
- **打印 · 矢量**：`--print-to-pdf` 出卡片版与侧栏版，均为 **1 页**，色块 / 底纹 / 双线全部保留。
- 临时验证脚本与截图全部放在系统临时目录，验证完删除，不进仓库。

## 已知取舍

- 侧栏版式「导出 HTML 再导入」会把左右栏拍平成文档顺序（技能在前）。数据不丢，但顺序会变；README 已写明。
- 时间轴 26mm 时间列里 `20XX.09 – 20XX.06` 会折成两行，这是列宽换「时间一眼可见」的代价，暂不调宽。
- 卡片版式的底纹靠 `--accent-bg`，与主题同源，主题换成深色系时会偏灰，属预期。
