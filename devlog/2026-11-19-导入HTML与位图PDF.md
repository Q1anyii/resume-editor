# 2026-11-19 导入 HTML、模块跳转条、修图像版 PDF

## 需求

1. 支持导入已有的简历 HTML 文件，自动解析并覆盖当前内容，之后直接对着改。
2. 在编辑器（左栏）左侧加一列模块跳转按钮。
3. 修「图像版（位图）PDF」导出错位：导出后只剩页面左侧一条窄内容、右侧大片空白，第二页空白。

## 方案

### 导入 HTML

`file://` 页面不能 `fetch` 本地文件，所以走 `<input type="file">` + `FileReader.readAsText('utf-8')` + `DOMParser`。

解析器 `parseResumeHtml(text)` 按本套简历模板（h1 / h2 / h3 / p / ul-li / strong+冒号）还原结构：

- `h1` → 姓名
- `h1` 到第一个 `h2` 之间的 `p`：以「求职意向 / 意向岗位 / 应聘岗位…」开头 → 求职意向行；含 `@`、手机号、`github.com`、`www.`、`http` → 联系行；其余按顺序拼成个人摘要
- 直接子元素里 `h2` 开新模块，按标题关键词判定模块类型：教育 / 项目 / 实习 / 技能（列表） / 段落
- `h3` 在项目型模块里开新条目；`p` 依模块类型处理（教育取 `<code>` 为时间、项目第一行取 meta、`class="proj-desc"` 取一句话描述、实习按 `｜` 拆公司与岗位）
- `li` 的 `strong`/`b` 后紧跟全角或半角冒号才算 label，否则整条当正文

应用时先 `confirm` 展示识别出的模块数与标题，确认后整体替换 `meta / modules / order`，保留 `layout / theme / ai`（排版、主题、API 配置不跟着换）。

### 模块跳转条

`.main` 里新增 `<nav class="rail" id="rail">`，位于编辑器最左侧，46px 宽。

- 按钮 = 「个人」+ 每个可见模块（取标题前 2 字，`title` 属性放全名）
- 点击 `scrollIntoView({behavior:'smooth', block:'start'})`
- 编辑器滚动时用 rAF 节流，按「卡片 top ≤ 76px」找当前模块高亮 `.rail-btn.on`
- 窄屏（≤1100px）与打印时隐藏

### 图像版 PDF

原来的实现把 A4 克隆体放进 `position:fixed` 的舞台再交给 html2pdf，实测导出成左侧窄条。改动三处：

1. **舞台回到文档流**：导出期间把 `.topbar` 与 `.main` 临时 `display:none`，`body` 临时改 `display:block`（页面是 flex 居中布局，克隆文档里会把盒子推偏），A4 盒子成为唯一内容、落在 (0,0)，渲染后再恢复。
2. **不传 `x / y / width / height`**：交给 html2canvas 按元素 `getBoundingClientRect()` 自己取景。
3. **`windowWidth / windowHeight` 贴着元素尺寸（`w+2 / h+2`）**：这是真正的根因，见下。
4. **盒子高度锁 1122px + `min-height:0`**：`297mm` 换算成 1122.5px，宽铺满 A4 时高会溢出半像素，jsPDF 多切一张空白页。

## 踩过的坑

- html2canvas 的 `windowWidth` 给大了（1400）会撑宽克隆文档，`.page` 在宽文档里被居中到 x≈303，于是取景区间 0–794 只截到左侧，表现为「内容右移、右侧被裁」。实测数据：`firstInkCol` 从 39%（≈310px）降到 1–6% 才正常。给 `Math.max(1400, …)` 是有害的，必须贴元素宽。
- `.page` 的 `min-height:297mm` 会让 `height:1122px` 失效（offsetHeight 仍是 1123），必须同时压 `min-height`，否则 PDF 仍出两页（第二页空白）。
- html2pdf 的 bundle **不暴露**全局 `html2canvas`（`typeof html2canvas` 恒 undefined），取 canvas 要用 `html2pdf().set(...).from(el).toCanvas().get('canvas')`；`.toCanvas().then(c=>…)` 的 `c` 是 `undefined`。

## 验证

headless Chrome 跑自测页（编辑器 + 注入样本 HTML + 断言块）：

- 解析：姓名 / 求职意向 / 联系行 / 摘要长度 / 4 个模块及条目数 / 项目 meta、技术栈、描述、5 条 bullet / 实习公司+岗位+时间 —— 全部与样本一致
- 跳转条：5 个按钮（个人 + 4 模块）
- 导出盒子：794 × 1122；主题变量与字号带入（`--accent #1a4d8f`、`--fs 9.3pt`）
- 渲染取景：canvas 794 × 1122，`firstInkCol 6%` / `lastInkCol 93%`，内容完整、左右留白对称
- 成品：`toPdf().get('pdf')` → `pdfPages 1`，页面 210.0 × 297.0mm
