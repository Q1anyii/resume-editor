# 模块折叠 + 条目（项目）拖拽调序

日期：2026-11-19
文件：`简历编辑器.html`

## 需求

1. 左栏越写越长，找模块要一直滚。每个板块（个人信息 / 排版 / 主题 / AI / 每个简历模块）的编辑区要能折叠起来。
2. 项目经历里现在只有 项目乙 / 项目甲 两条，但顺序是写死的：想先把 项目甲 提上去只能删掉重加。要能拖一下换位置（经历、教育、技能条目同理）。

## 实现

### 折叠

- 折叠状态放 `state.ui['f:<key>']`：模块用 `m-<模块id>`，固定面板用 `p-meta` / `p-layout` / `p-theme` / `p-ai` / `p-add`。`loadState()` 里补 `s.ui = s.ui || {}`，`DEFAULTS()` 补 `d.ui = {}`，老快照不会因为缺字段报错。
- 工具函数：`isFold(key)` 读状态，`toggleFold(key)` 切换后 `renderEditor()` + `save()`，`foldBtn(key)` 统一输出 `▾ / ▸` 按钮。
- 模板：每个 `.panel` / `.mod` 元素带 `data-panel` / 模块 id，并在 class 上拼 `collapsed`；头部右侧加 `foldBtn`（模块卡片用 `data-act="fold"`，固定面板用 `data-fold`）。
- CSS 四条：`.mod.collapsed .mod-body{display:none}`、`.panel.collapsed .panel-body{display:none}`，以及折叠时去掉头部下边框、模块头部底色加深（`#f5f8fc`）便于一眼看出收起状态。
- 点击走已有的 `editorEl` 委托：`data-fold` 分支优先处理固定面板，`act === 'fold'` 分支处理模块（拿到 `data-mod` 的 id 后转成 `m-<id>`）。

### 条目拖拽

- 模板：edu / project / intern / para 的容器 `.item` 加 `data-item="${i}"`，`item-head` 左侧改成 `<span class="item-label">` 包住新增的 `⠿`（`.ihandle`）与序号；list 型（技能）的条目容器是 `.bullet`，同样加 `data-item` 与手柄。
- CSS：`.item-head{gap:6px}`、`.item-label{display:flex;align-items:center;gap:4px}`、`.ihandle`（cursor:grab）、`.item.dragging / .item.over`，list 条目用 `.bullet.dragging[data-item]` / `.bullet.over[data-item]` 兜住。
- JS：`itemDrag = {mid, i}`，`bindItemDrag()` 绑手柄 dragstart/dragend 与整条 dragover/drop，`moveItem(mid, from, to)` 用 `splice` 移位后重绘 + 重新计算溢出与缩放 + 落库。
- `renderEditor()` 末尾的绑定顺序：`bindDrag()` → `bindBulletDrag()` → `bindItemDrag()`，左栏整体重绘后监听器全部重绑。

## 两处冲突处理

- **bullet 拖拽 vs 条目拖拽**：拖 bullet 时 `bulletDrag` 有值而 `itemDrag` 为 null，条目的 dragover 直接 return；拖条目时经过 bullet 元素，bullet 的 dragover 因 `bulletDrag` 为空不 `preventDefault`，事件自然冒泡到外层条目。bullet 的 drop 里保留 `stopPropagation()`，不会顺带触发条目换位。
- **模块拖拽 vs 条目拖拽**：模块级的 `dragId` 只在模块手柄 dragstart 时赋值，拖条目时 `dragId` 仍是 null，模块的 dragover/drop 会提前 return，不会误触发模块重排。

## 作用域约束

条目只能在同一模块内换位，跨模块不迁移（项目和经历属于不同栏目，搬过去等于改分类）；跨条目搬 bullet 仍不支持，理由见 `2026-11-19-bullet拖拽调序.md`。

无头 Chrome（`--headless=new --dump-dom`，注入 probe 在 `load` 后执行），12/12 PASS：

## 遗留

- 折叠状态存在 `localStorage` 的 `resume-editor-v1` 快照里，`导出配置` 会一并带出 `ui` 字段（重新导入时折叠状态跟着回来，属于预期行为）。
- 拖拽依赖 HTML5 `DragEvent`，触屏设备上不可用；目前只在桌面浏览器验证过。
