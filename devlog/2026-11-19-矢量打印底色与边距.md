# 2026-11-19 修「打印 · 矢量」丢底色与边距错位

## 问题

从编辑器点「打印 · 矢量」另存 PDF，出来的文件里：

1. 项目技术栈那行（`.r-code`，浅蓝底条）完全没有背景色，只剩文字；
2. 页面内容偏出右边，右边缘被裁。

## 根因

**丢底色**：Chrome 默认 `printBackground = false`，页面的 `background-color` 一律不绘制。`.r-code` 的底条正是纯 `background:var(--accent-bg)`，所以整条消失。

**错位**：print 规则里只清了 `.pv-scroll` / `.page` 的 transform 与 margin，没清 `html` / `body` 的默认 8px 边距，`.page` 也没有在打印态重设宽度。加上打印对话框「边距」若停在「默认」（0.4in），会覆盖 CSS 的 `@page{margin:0}`，可打印宽度只剩约 190mm 装 210mm 的内容 —— 按 100% 缩放时右侧被切。

## 修复

`<style>` 里的 `@media print`：

```css
@media print{
  @page{size:A4;margin:0}
  html,body{margin:0!important;padding:0!important;background:#fff}
  .page,.page *{-webkit-print-color-adjust:exact;print-color-adjust:exact}
  .page{transform:none!important;box-shadow:none!important;margin:0;width:210mm;max-width:210mm}
}
```

`print-color-adjust: exact` 是覆盖"不打印背景"这条默认的官方开关：即使打印对话框里没勾「背景图形」，带底色的元素照样出墨。

导出 HTML 的 `EXPORT_CSS` 里那段 print 规则同步加了同样的三件：`html/body` 归零、`.resume *` 全量 exact、宽度锁 210mm。

顺带把 `exportPdf()` 的提示改清楚：「目标『另存为 PDF』 · 纸张 A4 · 边距『无』 · 缩放保持默认；技术栈底条已强制打印，不用勾『背景图形』」。

## 验证

用 CDP `Page.printToPDF` 直接控制 `printBackground` 开关（headless 的 `--print-to-pdf` 默认会打背景，测不出问题）：

| 版本 | printBackground | 底条像素数 | 墨迹 bbox（150dpi） | 左右留白 |
|---|---|---|---|---|
| 旧版 | false（模拟未勾选） | **688** ≈ 无 | 76–1164 | 12.9 / 12.7 mm |
| 新版 | false | **19201** 完整 | 76–1164 | 12.9 / 12.7 mm |
| 新版 | true | 19201 | 76–1164 | 12.9 / 12.7 mm |

页面尺寸均为 209.9 × 297.0 mm、单页。左右留白差 0.2mm 来自字形边缘，不是排版偏移。

## 已知限制

- 打印对话框的「边距」是最终开关，用户改成「默认」时 `@page{margin:0}` 会被覆盖，内容会被整体缩小（不会裁切，但页边距变大）；界面提示已要求选「无」。
- `print-color-adjust` 只保证底色出墨，不影响打印机的"省墨"模式。
