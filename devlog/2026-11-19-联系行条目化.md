# 联系行条目化（select 选类型 + 自定义前缀 + 网址自动链接）

日期：2026-11-19
文件：`简历编辑器.html`

## 需求

把原来的一整行字符串

```
城市 ｜ 13800000000 ｜ you@example.com ｜ GitHub： https://github.com/yourname ｜ 作品： https://example.com
```

改成一个一个下拉（select）里的选项，允许自定义；涉及 URL 的都自动用 `href` 包装。

## 方案

### 数据模型

`meta.contact` 仍然是字符串——预览、导出、AI 都读它，不动。新增 `meta.contacts` 数组作为**编辑态真源**：

```js
{ kind: 'intent'|'phone'|'email'|'github'|'site'|'custom', label: '', text: '' }
```

- `CONTACT_KINDS` 六类，各带固定前缀：意向城市 `意向：`、电话/邮箱无前缀、GitHub `GitHub: `、作品/主页 `作品：`、自定义用条目自己填的 `label`
- `contactLine(c)` 单条拼回文本；前缀不以 `:`/`：` 结尾时自动补全角冒号
- `syncContact(meta)` 用 ` ｜ ` 连接所有条目，写回 `meta.contact`
- `splitContacts(str)` 反向拆：先认前缀（意向/GitHub/作品），再认纯邮箱、纯手机号，再认 `github.com`、`http(s)://` 或 `www.`，其余归自定义

### 兼容

三条入口都过 `normalizeMeta`：localStorage 旧快照（只有一行 contact）、导入的 JSON 配置、导入的简历 HTML。缺 `contacts` 就从 `contact` 拆；非法 `kind` 降级成 `custom`。`恢复默认` 与 `importHtml` 应用处也补了这一步，否则新导入的简历会渲染成空条目、而预览仍显示旧字符串。

### 交互

- 左栏个人信息里，原来那行输入框换成 `contactRows()`：每行 = 类型 select + 内容 input + `✕`，custom 时多一个 74px 的前缀输入框；底部 `＋ 添加一项`
- `input` 委托：path 以 `meta.contacts.` 开头时先 `syncContact()` 再重绘预览
- `change` 委托：select 带 `data-cidx` 时改 `kind` 后重绘左栏（自定义分支要显隐前缀框）
- `click` 委托：`data-cact="add"/"del"` 两个分支，放在 `if(!id || !act) return;` 之前（联系行不在 `.mod` 里，拿不到模块 id）

### 网址自动 href

重写 `linkify()`：先按正则切分原文，非链接段 `esc`、链接段补协议后包 `<a class="r-a" href target="_blank" rel="noopener">`。相比原先「整段 `esc` 再替换」，避免 URL 里的 `&` 被二次转义，同时缺协议的 `github.com/xxx`、`www.xxx` 都能拿到正确的 `https://` href。

| 类型识别 | `KINDS=intent,phone,email,github,site` |

| 预览链接数 | `HREFS=2` |
| 链接 href | `https://github.com/yourname`、`https://example.com` |
| 链接显示文本 | `github.com/yourname`（保留原文，不加协议前缀） |
| 左栏 select 行数 | `SELECTS=5` / `ROWS=5` |
| 改自定义前缀 | `CUSTOM_OK=true`（`电话：13800000000`） |
| 改回固定类型 | `BACK_OK=true` |

截图里左栏五行排版对齐，下拉显示完整（意向城市 / 电话 / 邮箱 / GitHub / 作品·主页），输入框与删除按钮同行不换行。

## 已知取舍

- 条目顺序只能用增删调整，没有 ↑↓（用户没提，暂不加）
- 前缀固定含全角冒号，与旧版简历文案一致；若以后要英文版需要另配一套 `CONTACT_KINDS`
