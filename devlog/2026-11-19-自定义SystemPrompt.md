# 2026-11-19 自定义 System Prompt

## 需求

AI 对齐 JD 的提示词写死在 `AI_SYSTEM` 常量里，只有一个版本。希望开一个口子：自己能改，不填就继续用默认。

## 做法

- `state.ai.systemPrompt` 新增字段，默认空串。旧快照与导入的配置由 `Object.assign({... systemPrompt: ''}, ...)` 补齐，不会因为缺字段变成 `undefined`。
- 取用逻辑收敛到一个函数，避免调用点各写一遍：

```js
function activeSystemPrompt(){
  const c = (state && state.ai && state.ai.systemPrompt) || '';
  return c.trim() || AI_SYSTEM;      // 空 → 内置默认
}
```

- `runAi()` 的 `messages[0].content` 改为 `activeSystemPrompt()`。
- UI 放在「API 设置」折叠区里、API Key 之后：一个等宽 mono 字体的大 textarea（132px 起，可上下拉，最高 300px），下面一行状态 + 两个按钮：
  - `当前生效：内置默认 · 1001 字` / `自定义 · N 字`
  - 「填入默认」：把 `AI_SYSTEM` 灌进输入框，方便在默认基础上改，不动真正生效的那份（因为还要再点输入才会写入 state）
  - 「恢复默认」：清空输入框，回落内置默认
- 输入事件里 `ai.*` 前缀本就不触发重绘（避免 textarea 失焦），所以只在 `ai.systemPrompt` 时额外调一次 `syncSysState()` 更新状态文字。
- 导出 JSON 配置会自动带上 `systemPrompt`（导出只剔 `api.key`），换机器可带走。

## 一个取舍

自定义是**完全替换**，不是「默认 + 追加」。替换后如果忘了保留「只输出 JSON」这条，`parseAiJson()` 会直接抛「返回内容不是 JSON」。所以 textarea 的 placeholder 和 README 都写了这句提醒。

兜底没有放开：`sanitizeChanges()` 里的 `AI_BLOCKLIST`（plan-and-execute、任务分解、「两个项目都公网部署」等）与字段白名单仍在代码里生效，自定义提示词也写不进这些内容。

## 验证

headless + CDP `Runtime.evaluate` 直接读请求体（fetch 被临时替换成返回固定 JSON 的桩函数）：

| 检查项 | 结果 |
|---|---|
| 初始状态行 | `当前生效：内置默认 · 1001 字` |
| 填入 `CUSTOM-TEST-PROMPT` 后实际发送的 system | `CUSTOM-TEST-PROMPT`（完全替换生效） |
| 清空后实际发送的 system | 等于 `AI_SYSTEM`，长度 1001 |
| 点「填入默认」 | 输入框内容 === `AI_SYSTEM`，状态行变「自定义 · 1001 字」 |
| 点「恢复默认」 | 输入框清空，状态行回「内置默认 · 1001 字」 |
| 脚本异常 | 无（`state` 等全局可正常访问，说明主脚本没有语法错误） |

另外截了 1500×2400 的整页图确认面板排版：新加的 textarea 与两个按钮在 API Key 与 JD 之间，宽度与其它输入框对齐，没有溢出。

## 后续修订：内置提示词改为通用版（同日）

原先那份写死了服务对象的届别、院校性质、目标岗位，还写进项目名、作品域名，并把简历里的一串具体指标列为「只能原样保留」的白名单。一旦把配置导出给同学，或点「填入默认」让人看，等于把简历的底牌摊开。

改写思路是把「具体事实」换成「事实边界」：

| 原来（个人信息） | 现在（通用规则） |
|---|---|
| 写死服务对象的届别、院校性质与目标岗位 | 删掉，只留「通用简历改写助手」定位 |
| 把简历里的具体数字逐条列为白名单 | 原文里的数字只能原样保留或整条删，禁止换算 / 放大 / 改小数 |
| 写死每个项目做到哪一步、哪个部署了 | 原文没提的不补；多个项目不得合并成「均已部署」；流程编排不得改写成任务规划 / 任务分解 / 多步规划 |
| 规定摘要不以特定届别 / 学历 / 专业开头 | 泛化成：不以届别、学历、专业开头 |

关键词检查：届别年份、院校性质、项目名、作品域名、简历里的指标数字，块内全部 0 命中，百分比数字正则也无匹配；长度从 1114 字符（1001 字）降到 920 字符（812 字）。请求体实测仍是这份，状态行显示「内置默认 · 812 字」。

代码层的 `AI_BLOCKLIST`（plan-and-execute / 任务规划 / 任务分解 / 多步规划 / 两个项目均已部署）不含个人信息，继续留作兜底，自定义提示词也绕不过它。
