# 默认数据改为通用结构模板，并清除历史里的真实简历内容

## 需求

上一轮已经把内置的 AI 提示词改成了通用版，但编辑器打开时加载的 `DEFAULTS` 仍然是作者本人的真实简历（姓名、电话、邮箱、项目、实习、指标全在里面）。要求：**默认数据换成一套结构模板（全占位符），README 与 devlog 里也不许出现个人信息，git 历史同样不能留。**

## 改动

### 1. `DEFAULTS` 整段替换为结构模板

字段结构一个不动（`meta` / `layout` / `theme` / `ai` / `order` / `modules`），只把内容换成占位符：

| 字段 | 现在的内容 |
|---|---|
| `meta.name` | `你的姓名` |
| `meta.jobTitle` | `求职意向（如：后端开发工程师）` |
| `meta.contact` | `意向：城市 ｜ 13800000000 ｜ you@example.com ｜ GitHub：github.com/yourname ｜ 作品：example.com` |
| `meta.summary` | 一句话写法提示（主攻方向 + 可量化成果 + 加分项，30–60 字） |
| `edu.items[0]` | `学校名称 ｜ 专业 ｜ 学历（全日制 · 20XX 届应届）｜ 相关证书` |
| `projects.items[0]` | 带 `stack` / `desc` / 两条带 `label` 的 bullet 写作提示 |
| `projects.items[1]` | 标注「没有就删掉这一条」，`desc: ''` |
| `intern.items[0]` | `公司名称` / `岗位名称（实习）` |
| `skills.items` | 主攻方向 / 相关技能 / 工程与部署三条提示 |

段长 3841 → 2066 字符，仍保留 `ai.systemPrompt: ''`（留空走内置提示词）。

同时中性化两处非内容残留：第 432 行注释里的旧版本说明、联系行输入框 placeholder（`城市，如 北京/全国`）。

### 2. README 与 devlog 脱敏

README 第 6 行改写为「首次打开加载的是通用结构模板，不含真实个人信息，实际简历只存在本机 localStorage」。devlog 与 README 里的实名/手机号/邮箱/GitHub 链接/项目名/指标用词表统一替换（`张三` / `13800000000` / `you@example.com` / `yourname` / `example.com` / `项目甲` / `项目乙` / `某大学` / `某科技公司` / `XX%` / `20XX`）。

> 词表替换必须大小写敏感，否则项目名里那些首字母大写的英文会连带命中代码里的 `sortState`、`sortStart` 这类驼峰标识符。

### 3. 重写历史

```
git filter-branch --tree-filter "python sanitize.py" -- --all
```

每个提交都重新注入上面那段模板 + 走一遍词表替换。10 个提交全部重写成功（日志里每提交一条 `html: DEFAULTS replaced (3xxx chars -> 2066)`）。

接着把作者/提交邮箱也换成中性地址（`dev@example.com`），避免真实邮箱与账号名留在提交元数据里：

```
git filter-branch --env-filter 'export GIT_AUTHOR_EMAIL=...; export GIT_COMMITTER_EMAIL=...' -- --all
```

| 逐提交逐文件扫描（10 提交 × 152 个 blob） | 0 个 blob 含特征串 |
| `git log -p --all --full-history` 全文搜索 | 除作者邮箱里的 GitHub 用户名外全部 False |
| `git rev-list --all` | 10 条（清理 `refs/original` + reflog + `gc --prune=now` 后） |
| HEAD 版本 headless 渲染 | `你的姓名` / `学校名称` / `项目名称` / `项目乙` / `公司名称` / `主攻方向` 全部出现在预览，旧数据不再出现 |
| `HEAD~1` 版本 headless 渲染 | DOM 展开到 129936 字符，表单 `value="你的姓名"` 与预览模板都在，旧姓名不存在 |
| 1500×1700 截图目视 | 左栏表单、8 主题、4 预设、AI 面板正常；右栏 A4 完整呈现模板 |

> 最早那个提交的版本在 headless 里是白屏——它当时用的是 CDN 版 jsPDF（按钮还叫「图像版 PDF」），断网时 CDN 阻塞内联脚本，属既有行为，与本次模板注入无关。

## 注意

- `filter-branch` 跑完必须删 `refs/original`、`reflog expire --expire=now --all`、`gc --prune=now`，否则旧对象仍在本地，`rev-list --all` 会数出双份。
- 用 `--tree-filter` 而非 `--index-filter` 时，替换逻辑写成一个幂等的 Python 脚本最省事：重复执行不会二次破坏（模板段再匹配一次也只是替换成同样内容）。
